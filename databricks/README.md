## Interview Focus Areas

### Delta Lake (Core)
- ACID transactions, time travel, schema evolution, MERGE, OPTIMIZE, VACUUM, concurrency control, streaming

### Databricks Platform
- Architecture, compute options, Unity Catalog, SQL Warehouses, Photon, Jobs, MLflow, security

### Data Engineering at Scale
- Performance tuning, cost optimization, data governance, cross-organization sharing, streaming reliability

### Production Architecture
- ETL pipelines, data quality monitoring, disaster recovery, cost management, security

## Usage

1. **Study the theory questions first** to build a strong foundation
2. **Practice the practical scenarios** to understand real-world application
3. **Focus on the Principal-level insights** for senior-level interviews
4. **Review the follow-up questions** to prepare for deeper discussions

## Prerequisites

- Strong understanding of Apache Spark
- Experience with data engineering at scale
- Knowledge of cloud platforms (AWS, Azure, GCP)
- Understanding of distributed systems and data architectures
